# 🍳 Recipe Page

A simple, responsive recipe page built with HTML5 and CSS3 as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

The page features an omelette recipe, including ingredients, preparation instructions, cooking time, and nutritional information.

## 🔗 Live Demo

[View the live project](https://charlesson-mp.github.io/recipe-page/)

## 🛠️ Technologies

- HTML5 — semantic page structure.
- CSS3 — responsive layout, custom fonts, and styling.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.

No additional dependencies or build tools are required.

## ✨ Features

- Responsive layout for desktop and mobile devices.
- Custom fonts for improved typography.
- Organized sections for preparation time, ingredients, instructions, and nutrition facts.
- Recipe image and clearly structured content.
